# 🚗 Auto Price Prediction Using Machine Learning

## 📌 Project Overview

Auto Price Prediction is a Machine Learning project that predicts the estimated price of a car based on its features. 
The project uses **Decision Tree Regression** and **Random Forest Regression** algorithms to estimate vehicle prices.

A Streamlit web application allows users to enter vehicle specifications, select a machine learning model, and view the predicted car price.

## 🎯 Objectives

* Predict car prices using Machine Learning.
* Perform data preprocessing and handle missing values.
* Train and compare Decision Tree and Random Forest regression models.
* Evaluate model performance using regression metrics.
* Build an interactive dashboard using Streamlit.

## 📊 Machine Learning Algorithms

### 1. Decision Tree Regression

Decision Tree Regression predicts car prices by learning decision rules from the input features.

### 2. Random Forest Regression

Random Forest Regression combines predictions from multiple decision trees to produce an estimated car price.

The application allows users to select either model and compare their performance.

## ⚙️ Project Workflow

1. Load the automobile dataset.
2. Explore and preprocess the data.
3. Handle missing values.
4. Prepare the input features and target variable (`price`).
5. Train regression models.
6. Evaluate the models using a train-test split.
7. Save the trained models and supporting files.
8. Build an interactive Streamlit dashboard.
9. Enter vehicle specifications and predict the estimated price.

## 📈 Model Evaluation

The project evaluates the models using the following metrics:

* **R² Score:** Measures how well the model explains variations in car prices.
* **RMSE (Root Mean Squared Error):** Measures prediction error while giving greater weight to larger errors.
* **MAE (Mean Absolute Error):** Measures the average absolute difference between actual and predicted prices.

The Streamlit dashboard displays these metrics for model comparison.

## ▶️ How to Run the Project


### Step 2: Open the project folder

```bash

```

### Step 3: Install dependencies


